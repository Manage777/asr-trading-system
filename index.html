05 / ABOUT

Independent trading software.

ASR Trading System is an independent software project developing tools for futures traders using NinjaTrader 8. The software is currently in final testing and preparation for commercial distribution.

The software assists with chart analysis, execution and trade management. Trading decisions, configuration and risk remain the responsibility of the user.
